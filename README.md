## 👋 About

I'm **James Smith**, an independent developer from the Netherlands 🇳🇱, building under the name **GalaxyModz** since 2021.

I build **Minecraft plugins, Fabric mods, Discord bots, websites and web tools**, and I **host servers and bots** for other people. Some of my work is sold on BuiltByBit, the rest is built custom for clients. What I care about: everything runs on the **latest versions**, works for **Java and Bedrock players**, and stays online **without babysitting**.

🎓 Codam Coding College, Amsterdam (core curriculum + advanced track)

## 🔭 Currently Building

**🗂️ GalaxyFiles**  
Edit your server files *from inside the game*. A Paper plugin and a Fabric client mod that talk over a plugin channel, so no RCON and no FTP. VS Code style editor with syntax highlighting, JSON formatting, reload buttons per plugin and a SQLite table viewer.

**🤖 OrbitBot v2**  
A full Java rewrite of my Bedrock AFK and survival bot. Reconnects forever, walks back home after dying, sleeps in beds and bridges chat between Minecraft and Discord in both directions. Runs 24/7 on Pterodactyl.

## 🌐 Websites & Web Tools

Besides Minecraft and Discord I build full websites and web tools, frontend and backend.

🏠 **Server & brand websites:** landing pages for Minecraft servers, Discord communities and creators  
📖 **Documentation sites:** setup guides and wikis, like [docs.galaxymodz.com](https://docs.galaxymodz.com)  
📊 **Dashboards:** admin panels that connect straight to your bots, databases or game servers  
🔌 **APIs & backends:** REST and GraphQL APIs, websockets, auth with JWT and OAuth  
🧩 **Custom tools:** anything your community needs in the browser
